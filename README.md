# MakerSite

Small maker portfolio site.

Files:
- `index.html` — main page
- `script.js` — JavaScript
- `style.css` — styles

Run locally:
- Open `index.html` in your browser.
- Start a simple local server (recommended):

```bash
# using Python
python -m http.server 8000

# or with npm (uses npx to avoid global installs)
npm start

# or for live reload
npm run live
```
